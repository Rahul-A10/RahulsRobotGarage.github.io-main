Problem statement

Manual microinjection in C. elegans is labor-intensive, time-consuming, and lacks the precision and scalability needed for high-throughput genetic studies. Automating this process is essential to enable large-scale CRISPR screening and behavioral research.

Abstract

This project presents an automated microinjection platform for C. elegans, integrating standardized preparation methods, immobilization of C. elegans, and precision needle control. A dual imaging system (macro and micro) combined with computer vision allows accurate detection and targeting. The hardware is driven by a software suite with a GUI that manages motion, pressure, and needle positioning. YOLO-based object detection aids worm localization, while hydrogel and anesthetics improve immobilization for injection.
